## Introduction

This repository contains my practical laboratory report on **PC System Fundamentals, Disk Sectors and Partition Analysis**.

The practical involved examining computer system specifications, running processes, storage devices, disk partitions and file systems using Windows and Kali Linux environments.

I also practised identifying disk sectors, calculating partition sizes and understanding how a computer starts up.

The exercise introduced me to different layers of digital evidence and how they can be collected during a forensic investigation.

## Objectives

The objectives of this practical were to:

- Examine computer system specifications.
- Identify hardware and operating system information.
- Observe running processes.
- Inspect storage devices and disk partitions.
- Identify different file systems.
- Calculate disk and partition sizes using sector information.
- Understand the computer boot process.
- Identify different layers of digital forensic evidence.
- Understand the importance of evidence preservation during forensic investigations.
